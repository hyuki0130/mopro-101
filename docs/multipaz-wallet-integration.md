# ProofPort Wallet Integration with Multipaz SDK

## 개요

이 문서는 Multipaz SDK를 활용하여 ProofPort 앱에 Digital Credentials Wallet 기능을 통합하는 방안을 설명합니다. Trust Manager를 활용한 B2B 비즈니스 모델과 함께 mDoc/mDL 발급 및 검증 플로우를 다룹니다.

## 9. 보안 고려사항

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           Security Considerations                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  1. 키 보호                                                                     │
│     • Private Key는 TEE(Secure Enclave/StrongBox)에만 저장                      │
│     • 키 추출 불가능 (하드웨어 보호)                                             │
│     • 생체 인증 바인딩으로 무단 사용 방지                                         │
│                                                                                 │
│  2. 자격증명 보호                                                               │
│     • Document Store는 디바이스 암호화 저장소 사용                                │
│     • 앱 삭제 시 자동 삭제                                                       │
│     • 백업 제외 (iCloud/Google 백업에서 제외)                                    │
│                                                                                 │
│  3. 통신 보안                                                                   │
│     • 모든 서버 통신은 TLS 1.3                                                  │
│     • Certificate Pinning 적용                                                  │
│     • Deep Link 파라미터 서명 검증                                              │
│                                                                                 │
│  4. Trust Manager 보안                                                          │
│     • 인증서 체인 완전 검증                                                      │
│     • 인증서 유효기간 확인                                                       │
│     • CRL/OCSP 검증 (선택적)                                                    │
│                                                                                 │
│  5. Presentation 보안                                                           │
│     • Session Transcript로 Replay Attack 방지                                   │
│     • Nonce를 통한 요청-응답 바인딩                                              │
│     • Reader Authentication 검증                                                │
│                                                                                 │
│  6. 사용자 동의                                                                 │
│     • 모든 데이터 공유 전 명시적 사용자 동의                                      │
│     • Selective Disclosure (필요한 claim만 공개)                                 │
│     • 동의 히스토리 로깅                                                         │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```
