# 상업용 ZK 비즈니스 모델 분석

> ZK(Zero-Knowledge) 기술 기반 상업용 서비스들의 비즈니스 모델, 펀딩, 수익 구조 심층 분석

---

## 1. 개요

### 1.1 ZK 상업화 현황

| 구분 | 특징 | 대표 프로젝트 |
|------|------|--------------|
| **상업용 (B2B/B2C)** | 수익 모델 존재, 펀딩 유치 | Self Protocol, Civic, Humanity Protocol |
| **그랜트 기반** | 생태계 펀딩, 오픈소스 | ZKEmail, z-imburse |
| **교육/데모** | 학습 목적, 비영리 | GitClaim, ZK-Flexor |

## 2. 프로젝트 분류 체계

### 2.1 Awesome Noir "Commercial" 카테고리 분석

| 프로젝트 | 설명 | 실제 상업화 여부 | 수익 모델 |
|----------|------|-----------------|----------|
| **GitClaim** | GitHub 기여도 기반 에어드랍 | ❌ 교육용 샘플 앱 | 없음 |
| **z-imburse** | 프라이버시 경비 정산 | ⚠️ 그랜트 기반 | Noir Research Grant |
| **ZK-Flexor** | EVM 자산 잔고 증명 | ❌ 해커톤 프로젝트 | 없음 |

**핵심 발견**: Awesome Noir의 "Commercial" 카테고리에 있는 프로젝트들은 실제로 상업적 비즈니스 모델이 아닌, **상업적 사용 사례(use case)**를 보여주는 데모/교육용 프로젝트입니다.

### 2.2 실제 상업화된 ZK 신원 서비스

| 프로젝트 | 펀딩 | 사용자 | 수익 모델 | 파트너 |
|----------|------|--------|----------|--------|
| **Self Protocol** | $9M Seed | 8M+ | B2B SDK 라이선스 | Google Cloud, Aave |
| **ZKPassport** | $500K (a16z) | - | B2B API | Aztec Network |
| **Humanity Protocol** | $1.1B 밸류에이션 | - | 토큰 이코노미 | - |
| **Civic** | Series A+ | 200만+ 검증 | B2B SaaS | Solana 생태계 |

## 5. ZKPassport vs ZKEmail 비교

### 5.1 상업화 현황

| 항목 | ZKPassport | ZKEmail |
|------|-----------|---------|
| **조직 형태** | 영국 등록 회사 (Ltd) | 오픈소스 프로젝트 |
| **펀딩** | $500K (a16z) | 그랜트 (PSE, 0xPARC, Gitcoin) |
| **수익 모델** | B2B SDK 라이선스 | 없음 (무료 오픈소스) |
| **상업적 파트너** | Aztec, 기업들 | 없음 |
| **가격 정책** | 비공개 (협상) | 무료 |

### 5.2 왜 ZKEmail은 상업화하지 않는가?

## 10. 결론

### 10.1 핵심 발견

1. **Awesome Noir "Commercial" ≠ 실제 상업 서비스**
   - GitClaim, z-imburse, ZK-Flexor는 모두 교육/그랜트 기반 프로젝트
   - "Commercial"은 상업적 **사용 사례**를 의미

2. **ZKPassport vs ZKEmail**
   - ZKPassport: 상업화 진행 중 (a16z 투자, 회사 설립)
   - ZKEmail: 의도적으로 Public Good으로 유지 (그랜트 기반)

3. **실제 상업화 성공 사례**
   - Self Protocol: $9M 펀딩, 8M 사용자, Google Cloud 파트너
   - Humanity Protocol: $1.1B 밸류에이션
   - Civic: 200만+ 검증, Solana 생태계

4. **주요 비즈니스 모델**
   - B2B SDK 라이선스 (가장 일반적)
   - 검증당 과금
   - 토큰 이코노미
   - 하드웨어 + 서비스

### 10.2 시장 기회

```
ZK KYC 시장: 2025년 $83.6M → 2032년 $903.5M (CAGR 40.5%)
```

**ProofPort 포지셔닝 권장**:
- 모바일 네이티브 ZK 증명의 차별성 강조
- 멀티 KYC 소스 지원으로 범용성 확보
- B2B SDK 모델로 지속 가능한 수익 구조 구축
